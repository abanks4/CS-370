For this project, I worked on developing an intelligent agent that could navigate an 8x8 maze and find the treasure before the human player using deep Q-learning. I was provided with starter code that included the maze environment, neural network structure, and supporting functions. My main responsibility was completing the qtrain() function using the pseudocode provided as a guide. I wrote the training loop to randomly select starting positions, initialize the environment state, and use an epsilon greedy strategy to balance exploration and exploitation. I also implemented the code to track wins and losses, retrieve training data, and train the neural network.
